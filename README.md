# EMERALD SHOP
## A simple shopping app where you can view products and add items to cart.

1. Download and Install MongoDB [<https://www.mongodb.com/docs/manual/installation/>]
2. Download and Install Node.js [<https://nodejs.org/en/download/>]
3. Open Node.js and install Express. [<https://expressjs.com/en/starter/installing.html>]

4. Run the mongoshell or MongoDB Compass to import the collections.

    _First create a database name `emeraldshop`. Then import the two collections which is save as `json` files. `products` and `productcarts`. The json files were located in the json folder on the project root directory._

5. Navigate inside emeraldshop folder

    _Run these commands in the Terminal:_

         cd emeraldshop

6. Start the database/server by running `nodemon` or `node app.js`.

    _Run these commands in the Terminal:_

         node app.js


7. Start the client side by running `ng serve`.

    _Run these commands in the Terminal:_

         cd clientside
         ng serve
